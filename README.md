# Hangman Game 🎮

## Project Overview

This is a simple Hangman Game developed using Python.
The player has to guess the hidden word by entering letters.

## Technologies Used

- Python
- VS Code

## Features

- Random word selection
- Letter guessing
- Limited attempts
- Displays guessed letters
- Win or lose result

## How to Run

1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run:

python hangman.py
